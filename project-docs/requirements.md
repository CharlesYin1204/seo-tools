# 需求与功能规范

## 重要业务规则 ⚠️

### 1. 地图房源数据一致性规则 【必须遵守】

**规则描述**：
- 地图显示的房源数据必须和用户中心的所有房源数据保持一致
- `/map-search?user=xxx` 页面必须显示所有已上架的房源（`is_listed = 1`）
- **禁止按用户过滤房源** - 不管 URL 中有没有 user 参数，都要显示全部已上架房源

**代码位置**：
- 控制器：`app/Controllers/Frontend/HomeController.php` 的 `mapSearch()` 方法
- SQL 查询：`WHERE is_listed = 1`，不加用户过滤条件

**违反后果**：
- 2026-01-14：错误地添加了按用户过滤导致地图只显示 0 条房源，已修复

---

## 房源展示规范

### 已上架房源 (is_listed = 1)
- 在首页房源列表显示
- 在地图搜索页面显示
- 在用户房源分享页面显示
- 支持搜索和筛选

### 未上架房源 (is_listed = 0)
- 仅在用户后台管理中显示
- 不在前端公开页面显示

---

## 地图功能规范

### 高德地图配置
- 使用高德地图 JS API v1.4.15（支持英文底图）
- 地图语言：英文（`lang: 'en'`）
- 默认中心点：上海市中心（121.4737021, 31.2304324）
- 默认缩放级别：PC端 12，移动端 14-16

### 房源标记
- 显示所有有经纬度的房源
- 无经纬度的房源在列表中显示但不在地图上标记
- 支持标记聚合（MarkerCluster）
