# 高德地图 API 免费方案与竞品分析

> 文档日期：2026-03-03  
> 依据来源：高德开放平台定价页 https://lbs.amap.com/upgrade#price

---

## 一、能否免费使用高德地图 API？

**可以免费使用。** 高德对个人认证、企业认证开发者均提供**免费月配额**，在配额内调用不收费；超出配额后才按量计费或需购买流量包/技术服务许可。

---

## 二、免费额度与功能一览（每月）

### 1. 三类账号的月配额对比

| 服务类型 | 个人认证开发者 | 企业认证开发者 | 企业认证+技术服务许可（基础版 5万/年） |
|---------|----------------|----------------|----------------------------------------|
| **基础 LBS 服务** | 150,000 次 | 3,000,000 次 | 9,000,000 次 |
| **基础搜索服务** | 1,500,000 次 | 30,000,000 次 | 90,000,000 次 |
| **基础地图定位服务** | 5,000 次 | 50,000 次 | 500,000 次 |
| 其它-智能硬件定位 | 5,000 次 | 5,000 次 | 9,000,000 次 |
| 其它-天气预报 | 0 次 | 5,000 次 | 9,000,000 次 |

- **配额说明**：基础 LBS、基础搜索、基础地图定位等，在 API / JS / Android / iOS / 微信小程序等平台**共享**同一账号下的对应配额。
- **消耗顺序**：先消耗当月免费配额，超限后可付费购买流量包或按次计费。

### 2. 各服务包含的功能（免费配额内可用）

- **基础 LBS 服务**  
  路径规划（驾车/骑行/步行/公交）、距离测量、地理编码、逆地理编码、坐标转换、行政区划查询、IP 定位、静态地图。

- **基础搜索服务**  
  关键字搜索、周边搜索、多边形搜索、ID 查询、输入提示。

- **基础地图定位服务**  
  - **JS 地图图面初始化**（前端 `webapi.amap.com` 加载地图，按“次”计费，程序生命周期内算 1 次）  
  - 在线定位（Android 等）。

- **其它基础服务**  
  智能硬件定位、天气预报等（见上表配额）。

### 3. 超限后的价格（参考）

- 基础 LBS 服务：**30 元/万次**
- 基础搜索服务：**30 元/万次**
- 基础地图定位服务：**3 元/万次**
- 用量越大折扣越高（如 30–100 万次可享约 8 折等，以控制台为准）。

## 三、免费使用方案建议（结合本站）

### 本站当前使用的高德能力

| 用途 | 接口/方式 | 对应高德服务类型 |
|------|-----------|------------------|
| 地理编码、逆地理、POI 搜索 | `restapi.amap.com`（geocode/geo、regeo、place/text） | 基础 LBS + 基础搜索 |
| 前端地图展示、选点、聚类 | `webapi.amap.com`（JS API 地图初始化、Geocoder、PlaceSearch、MarkerCluster 等） | 基础地图定位（JS 地图图面初始化） |

### 免费方案要点

1. **优先做企业认证（若主体允许）**  
   - 企业认证后，基础 LBS 与基础搜索的免费额度远高于个人（如 300 万/3000 万），一般中小型站点在免费额度内够用。  
   - 基础地图定位从 5,000 次/月 提升到 **50,000 次/月**，对前端地图访问量更友好。

2. **重点控制「基础地图定位」消耗**  
   - 个人仅 **5,000 次/月**，最容易先超限。  
   - 每次加载地图页（JS 地图初始化）计 1 次，刷新、新开页都会累计。  
   - 建议：  
     - 地图页做懒加载或按需打开，减少无效加载；  
     - 避免同一会话内重复初始化地图（单页内只初始化一次）；  
     - 若 PV 较高，可考虑企业认证或评估是否需购买「基础地图定位」流量包（3 元/万次）。

3. **后端接口（地理编码、POI）**  
   - 本站已有本地缓存、小区知识库等（如 `PropertyGeocodingService`），能显著减少对高德 restapi 的调用。  
   - 在企业认证下，300 万 LBS + 3000 万搜索的免费额度对一般房源/地图应用通常足够。

4. **不买 5 万/年也能免费**  
   - **5 万/年**是「技术服务许可」基础版，主要带来：更高月配额（如地图定位 50 万/月）、超限应急、SLA、合规与技术支持等。  
   - 若月调用量在「企业认证免费配额」内，可以**不购买**，完全在免费额度内使用。

5. **乘风计划（定向邀请）**  
   - 高德有针对初创/小微企业的「乘风计划」，符合条件可免费获得一定期限的企业级基础服务。  
   - 目前为**定向邀请**，可在高德开放平台或工单中咨询是否适用。

## 四、5 万/年「技术服务许可」基础版包含什么？

- **合规与授权**：使用高德对外公开的基础 LBS、基础地图定位、基础搜索服务所需的**授权**。  
- **更高月配额**：如基础 LBS 900 万/月、基础搜索 9000 万/月、**基础地图定位 50 万/月**等。  
- **超限与保障**：每月第 1 次超限可享短时应急额度；可选超限流量保障（如基础 LBS 日配额临时 2 倍等）。  
- **SLA**：API 可用性 ≥99.95%，响应时间等承诺。  
- **支持**：工单响应、智能客服、专属服务群、风险报警、月报等（具体以官网/合同为准）。

适合：日活/调用量较大、需要合规授权或稳定 SLA 的团队。若当前量级不大，可先在企业认证免费额度内使用，再按需考虑是否购买。

## 五、竞品 unido.luckinhouse.com 分析

### 5.1 能直接看到的信息

- 当前仅能访问**登录页**（公寓租赁企业登录、Unido 管理系统），无法进入系统内部。  
- 无法从公开页面上直接判断：  
  - 是否使用高德地图；  
  - 是否付费；  
  - 是否购买了「5 万/年」技术服务许可。

### 5.2 是否「付了 5 万一年」的结论

- **无法仅通过该网站公开内容得出「付了 5 万/年」或「没付」的结论。**  
- 若竞品使用了高德且调用量较大，有可能：  
  - 仅用企业认证免费配额；  
  - 或购买了流量包/技术服务许可（5 万/年或 10 万/年高级版）。

### 5.3 若需进一步判断，可考虑

1. **登录后查看**  
   - 是否有地图选房、地图找房、POI 搜索、路线规划等；  
   - 若有，打开浏览器开发者工具 → Network，看是否请求 `webapi.amap.com`、`restapi.amap.com` 或携带高德 key 的域名，可判断是否接入了高德。

2. **高德官方查询**  
   - 高德提供「技术服务许可证书信息查询」：  
     https://lbs.amap.com/commercial  
   - 若知道竞品公司全称或证书信息，可在该页面查询其是否已购买技术服务许可（不保证所有购买方都会公开）。

3. **行业常见做法**  
   - 公寓/租赁 B 端系统若带地图能力，常见做法是：  
     - 使用高德/百度等国内地图，企业认证 + 免费额度或按量付费；  
     - 部分中大型或重合规客户会购买技术服务许可（如 5 万/年）以获取更高配额与合规保障。  

因此，**不能根据「竞品用了地图」就推断其一定付了 5 万/年**，只能通过上述方式做合理推断或查询。

## 六、总结表（免费 vs 付费）

| 维度 | 免费使用（个人/企业认证，不买许可） | 付费（例如 5 万/年 技术服务许可基础版） |
|------|-------------------------------------|----------------------------------------|
| 是否可行 | ✅ 可以，在月配额内免费 | 适合高用量、要合规与 SLA 时 |
| 地图初始化（JS） | 个人 5千/月，企业 5万/月 | 50万/月 等更高配额 |
| 地理编码/路径/POI 等 | 个人 15万 LBS + 150万 搜索；企业 300万 + 3000万 | 900万 + 9000万 等 |
| 超限后 | 按量付费或买流量包 | 有超限应急与更高配额 |
| 合规与支持 | 基础使用 | 授权、SLA、工单与专属支持等 |

**建议**：  
- 先完成**企业认证**，在免费配额内优化调用（尤其控制前端地图初始化次数）。  
- 根据实际调用量与业务需求，再决定是否购买流量包或 5 万/年技术服务许可。  
- 竞品是否付 5 万/年需通过登录后抓包或高德官方许可查询等方式进一步确认，无法仅从 unido 登录页得出结论。
