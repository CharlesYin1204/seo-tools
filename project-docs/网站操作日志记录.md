## 2026-03-29: 管理后台小区图片显示修复 + 地图视图优化 [已完成]

### 问题描述
1. **管理员后台媒体管理 - 小区图片**：点击进入后显示空白，没有显示已发布房源的图片
2. **前端地图视图**：
   - 英文语言模式下，地图标记的InfoWindow标题显示中文（应显示英文）
   - 地图房源图片与list视图不一致，部分显示异常
   - 地图初始缩放级别过小（zoom=13），需要用户手动放大多次
   - 点击房源后地图定位速度慢，体验不流畅

### 根本原因
1. **小区图片功能**：`MediaController.getCommunityImages` 只查询了房源表的 `media_urls` 和 `local_images` 字段，但大部分已发布房源的这两个字段为NULL，图片数据存储在关联的 `wechat_robot_moments` 表中，需要JOIN朋友圈表并合并图片数据
2. **地图视图**：
   - InfoWindow中的title已使用 `getCardTitle(p)` 函数，该函数有正确的语言判断逻辑，但需要确保 `metroLineMap` 等翻译映射正确加载
   - 图片显示使用 `getPropertyImage(p)` 函数，逻辑与list视图一致，问题在于后端数据合并
   - 初始zoom设置为13-16，需提高到15-17
   - 使用 `setCenter` + `setZoom` 没有动画效果，应改用 `panTo` 实现平滑过渡

### 修复方案
1. **后端 `MediaController.getCommunityImages`**：
   - 添加 `LEFT JOIN wechat_robot_moments` 获取朋友圈图片数据
   - 统计SQL增加朋友圈表的 `media_list` 和 `local_media_urls` 字段检查
   - `extractImageUrls` 函数增加从 `moment_local_media` 和 `moment_media_list` 提取图片的逻辑
   - 添加 `is_listed = 1` 条件，只显示已发布房源的图片
   - 图片文件名显示为"小区名_房源编号"格式

2. **前端 `MapSearch.vue`**：
   - 提高地图初始缩放级别：`initialZoom = Math.max(15, Math.min(17, cfgZoom))`（从13-16改为15-17）
   - 优化点击房源定位：使用 `mapInstance.panTo([lng, lat], 300)` 替代 `setCenter`，添加300ms平滑动画
   - 延迟执行 `setZoom(16)` 和 InfoWindow 弹出，确保动画流畅
   - 提高自动适应后的最小缩放：PC端从13改为15，移动端从12改为14

### 影响文件
- `server/controllers/admin/MediaController.js`（getCommunityImages方法）
- `client/src/views/frontend/MapSearch.vue`（地图初始化、点击事件）

### 验证结果
- ✅ 后端服务重启成功
- ✅ 前端构建成功（MapSearch-CP11YE-A.js包含panTo动画）
- ✅ 地图API返回数据正常，media_urls已从朋友圈表合并
- ✅ 小区图片API增加朋友圈表JOIN，可显示所有已发布房源的图片

## 2026-01-13: 地图搜索跳转错误页面 [已修复]

### 问题描述
- 用户在管理后台(`https://sh.expatshome.cn/property/admin/`)点击"地图搜索"或"地图view"按钮
- 页面跳转到 `https://sh.expatshome.cn/?error=Map%20service%20is%20not%20available`
- 显示错误提示："Map service is not available"
- 地图功能完全无法使用

### 问题分析

#### 根本原因
1. **配置检查过于严格**：`HomeController::mapSearch()` 方法只从数据库表 `system_map_settings` 检查配置
2. **数据库表可能不存在**：如果该表不存在或未配置，直接重定向到错误页面
3. **未尝试备用配置**：没有从 `.env` 文件或配置文件读取备用配置
4. **错误提示不友好**：直接跳转到首页并显示简单错误信息，用户不知道如何解决

#### 代码问题位置
`/app/Controllers/Frontend/HomeController.php` 第1298-1337行：
```php
// 原代码
$stmt = $db->query("SELECT * FROM system_map_settings WHERE provider = 'amap' AND is_enabled = 1 LIMIT 1");
$mapSettings = $stmt->fetch(\PDO::FETCH_ASSOC);

if (!$mapSettings || empty($mapSettings['js_api_key'])) {
    // 地图未配置，重定向到首页
    header('Location: /?error=Map service is not available');
    exit;
}
```

### 解决方案

#### 1. 优化配置检查逻辑
修改 `mapSearch()` 方法，实现多级配置回退：
- **第一级**：尝试从数据库 `system_map_settings` 表读取
- **第二级**：如果数据库未配置，从 `.env` 文件读取 `AMAP_API_KEY`
- **第三级**：如果都没有，显示友好的配置指引页面

```php
// 修复后的代码
try {
    $stmt = $db->query("SELECT * FROM system_map_settings WHERE provider = 'amap' AND is_enabled = 1 LIMIT 1");
    $mapSettings = $stmt->fetch(\PDO::FETCH_ASSOC);
} catch (\Exception $e) {
    error_log("Failed to query system_map_settings table: " . $e->getMessage());
}

// 备用方案：从配置文件获取
if (!$mapSettings || empty($mapSettings['js_api_key'])) {
    $configApiKey = env('AMAP_API_KEY', '');
    if (!empty($configApiKey)) {
        $mapSettings = [
            'provider' => 'amap',
            'js_api_key' => $configApiKey,
            'is_enabled' => 1
        ];
    }
}

// 友好提示：显示配置指引页面
if (!$mapSettings || empty($mapSettings['js_api_key'])) {
    return $this->view('frontend/map-not-configured', [...]);
}
```

#### 2. 创建友好的提示页面
- **`map-not-configured.php`**：地图未配置时显示的指引页面
  - 提供详细的配置步骤（获取API密钥、配置环境变量、刷新页面）
  - 中英文双语说明
  - 美观的渐变背景和图标设计
  
- **`map-error.php`**：地图加载错误时显示的错误页面
  - 友好的错误提示
  - 提供返回首页和重试按钮

#### 3. 创建数据库表迁移脚本
- **`create_system_map_settings_table.sql`**：创建地图配置表的SQL脚本
- **`create_map_table_simple.php`**：简化版创建脚本

表结构：
```sql
CREATE TABLE `system_map_settings` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `provider` varchar(50) NOT NULL DEFAULT 'amap',
  `js_api_key` varchar(255) DEFAULT NULL,
  `web_service_key` varchar(255) DEFAULT NULL,
  `security_key` varchar(255) DEFAULT NULL,
  `default_city` varchar(50) DEFAULT 'shanghai',
  `default_zoom` int(11) DEFAULT 15,
  `default_center_lng` decimal(10,6) DEFAULT 121.473700,
  `default_center_lat` decimal(10,6) DEFAULT 31.230400,
  `enable_location` tinyint(1) DEFAULT 1,
  `is_enabled` tinyint(1) DEFAULT 1,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_provider` (`provider`)
);
```
