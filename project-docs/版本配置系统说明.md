# 版本配置系统说明

## 概述

系统支持两种版本类型：

1. **SaaS 多租户版** (`saas`) - 完整功能版本
2. **独立版** (`standalone`) - 企业内部使用版本

## 版本区别

### SaaS 多租户版
- 支持多用户注册和登录
- 支持在线支付功能
- 会员套餐管理
- 积分和邀请推广系统
- 完整的管理后台功能
- 用户中心完整功能

### 独立版
- **仅允许管理员登录**
- 禁用用户注册功能
- 管理员后台仅保留：
  - 微信机器人模块
  - 存储配置
  - 网站设置
  - 系统版本管理
- 用户中心仅保留：
  - 微信机器人模块
  - 媒体管理
  - AI模型管理
  - 个人设置

## 配置文件结构

系统使用两个独立的配置文件来分离版本配置和数据库配置：

### 1. 版本配置文件 (可加密)
**文件路径**: `config/edition.config.php`

```php
// 版本类型：'saas' 或 'standalone'
define('SYSTEM_EDITION', 'saas');
```

此文件控制系统版本类型，可以被代码加密工具加密。

### 2. 数据库配置文件 (不可加密)
**文件路径**: `config/database.local.php`

```php
return [
    'host' => 'localhost',
    'port' => 3306,
    'database' => 'your_database',
    'username' => 'your_username',
    'password' => 'your_password',
    'charset' => 'utf8mb4',
];
```

此文件包含数据库连接信息，由安装程序自动生成，**不应被加密**。

## 安装时版本选择

在安装程序的第三步（系统配置）中，用户可以选择版本类型：

1. 运行安装程序 `/install/`
2. 完成环境检查（步骤1）
3. 配置数据库（步骤2）
4. 在系统配置页面（步骤3）选择版本类型
5. 完成安装

## 版本检测函数

系统提供以下辅助函数用于检测版本类型：

```php
// 检查是否为独立版
is_standalone_edition();  // 推荐使用
is_standalone_mode();     // 向后兼容

// 检查是否为SaaS版
is_saas_edition();        // 推荐使用
is_saas_mode();           // 向后兼容

// 检查功能是否启用
is_feature_enabled('payment');
is_feature_enabled('membership');
is_feature_enabled('user_registration');

// 检查模块是否允许访问
is_admin_module_allowed('wechat-robot');
is_user_module_allowed('ai-model');
```

## 切换版本类型

如需切换版本类型，只需修改 `config/edition.config.php` 文件中的 `SYSTEM_EDITION` 常量：

```php
// 切换为独立版
define('SYSTEM_EDITION', 'standalone');

// 切换为SaaS版
define('SYSTEM_EDITION', 'saas');
```

修改后刷新页面即可生效。

## 代码加密说明

当需要对代码进行加密保护时：

1. **可以加密的文件**：
   - `config/edition.config.php` - 版本配置
   - `config/config.php` - 主配置文件
   - 所有 PHP 业务逻辑文件

2. **不可加密的文件**：
   - `config/database.local.php` - 数据库配置（用户需要可编辑）
   - `install/` 目录 - 安装程序
