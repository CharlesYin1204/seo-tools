# SEO AI 用户中心功能说明

## 站点与审计
用户填写真实公网 URL，系统通过 `safeFetch` 抓取首页、robots.txt 和 Sitemap，按同域名去重后写入 `seo_pages`，再由确定性规则计算技术结构、内容结构和覆盖率。站点所有权验证仅用于保护发布能力；Google Search Console 作为独立的数据导入连接，不再承担验证职责。

## 页面分数与元数据
页面分数来自最近一次扫描保存的事实模型。标题与摘要候选必须在页面分数上下文中生成：后端读取已扫描页面事实和管理员启用的 AI 模型，生成 Title/Description，写入 `seo_change_candidates`，并经过审核后才能导出或发布。候选 URL 始终来自 `seo_pages.url`，禁止使用模型返回的 URL。

## 内容优化、内链、结构化数据
三个模块都以当前组织已扫描页面为输入。内容优化读取页面正文、标题、H1、Schema 和问题证据生成简报；内链建议只推荐同站已发现 URL，并校验来源页与目标页不能相同；结构化数据先解析页面 JSON-LD，再生成缺失字段候选并执行 JSON 语法校验。没有扫描证据时显示“请先扫描”，不得生成静态示例。

## 外链权威
外链权威是独立的第三评分维度，管理员后台“SEO AI > 外链权威配置”可配置 Ahrefs API endpoint、token 和刷新周期。扫描时由服务端调用 Ahrefs API，成功结果按域名写入 `seo_authority_metrics`；刷新周期内复用真实缓存以控制 API 成本。API 失败时仅使用最近一次真实缓存并标记 `stale`，没有历史值则显示“未配置/暂不可用”，绝不伪造分数。报告页读取评分模型中的外链分和来源状态，不再硬编码“待接入”。

## 发布与检查
发布流程为：候选审核通过 -> 管理员审核连接器 -> 用户健康检查 -> 加密认证后提交发布请求 -> 重新扫描原 URL -> 对比真实 Title/Description -> 写入任务和审计日志。WordPress、REST 和 Webhook 使用统一 HTTPS JSON 协议，支持 Bearer、Basic 和 HMAC；凭据以 AES-256-GCM 加密且不回显。只有远端返回 2xx 且复扫内容完全匹配时才显示“已发布并验证”，否则保留失败证据并允许重试，绝不记录模拟成功。

## GEO 可发现性
检查目标站点真实的 `/llms.txt`、页面 robots/noindex、可引用事实和结构化数据。即时结果绑定当前组织、站点 ID 与精确扫描 URL；趋势落库需在监测任务模块启用后提供，当前页面不伪造历史趋势。

## 底层数据逻辑
所有用户查询通过 organization_id 隔离；AI 用量在候选成功写入后才结算；失败、超时和无效 JSON 不扣点。前端只展示 API 返回的数据，不使用硬编码业务结果。
# 运行时接口一致性补充（2026-09-04）

用户中心统一通过 `/api` 请求后端。认证资料、SEO 扫描、报告、站点连接和发布复扫不再因当前页面 URL 或反向代理规则不同而请求到 SPA 路径。外链权威未配置时明确显示“待配置 / 未配置”，不会把缺失数据展示为 0 分或空状态。

## 专项分析闭环修复（2026-09-04）

内容优化、内链建议、结构化数据和 GEO 页面不再把请求误发到旧的通用扫描接口。用户从当前工作区的真实已扫描页面列表选择目标，专用接口按组织和精确 URL 二次校验并保存历史。

内容简报展示原页面标题、摘要、正文长度、标题层级、正文证据和待改进项；简报中的 `page_url` 固定取自 `seo_pages.url`。内链模块展示真实锚文本和 nofollow 状态，并只从同站同批次扫描页面计算未链接机会。Schema 模块逐块验证实际 JSON-LD，并生成只包含已抓取事实的 WebPage 候选。GEO 模块实时检查 llms.txt、robots.txt、四类 AI 爬虫规则、索引能力、内容充分度和引用准备度。每次结果写入 `seo_feature_analyses`，界面显示真实历史编号，不再用按钮伪称已创建变更单。

## 发布工作区闭环（2026-09-04）

“发布与检查”是独立的真实任务工作台，不再复用通用功能占位页。顶部统计可发布、发布中、已验证和失败任务；连接区展示站点、连接器类型、认证方式、审核状态、最近健康检查状态与时间，但永不返回凭据；候选区展示固定原 URL 的标题与描述；任务区展示远端 HTTP 状态、响应摘要、错误原因以及复扫标题和描述是否匹配。已导出的候选仍可继续发布。没有通过 HTTP 2xx 健康检查的活动连接器时，发布会明确阻断且不修改候选、不新增任务。

## Google Search Console 真实导入（2026-09-04）

GSC 与站点所有权验证完全分离。用户添加站点后可单独授权 Search Console；系统仅接受 Google 账号中与站点主机精确匹配且权限有效的 property。OAuth 成功后立即导入最近 28 天的真实点击、曝光、CTR、平均排名，并通过 URL Inspection 获取首页索引结论和覆盖状态。站点卡片显示指标、property、权限、同步时间及索引状态，支持手动同步和断开。令牌加密且不回显；断开操作同时覆盖令牌并删除本地指标。管理员未配置 OAuth 时明确显示不可用，不生成连接或模拟指标。
